Icon prompts

Twelve icons for the HUD. Each prompt below is self-contained — paste one at a time. Do all twelve in a single ChatGPT conversation, in order, so it carries the style forward. A set that doesn't match is worse than no icons at all.

The palette

Every prompt restricts itself to these, so the icons sit inside the game's existing colours instead of next to them.

#E07A3B burnt orange
#B24C18 deep rust
#EDE7DC brushed silver
#A79C8C muted tan
#5FA082 teal green
#14110F near-black

The one thing that will ruin these: they render at roughly 18–24 pixels in game. Anything finer than a chunky stroke disappears entirely. Every prompt says so — don't soften that line if you rewrite it, and judge each result by shrinking it to thumbnail size, not by how it looks at full resolution.

Hover variants

The icons above are the rest state. For anything that sits on a button, a second version gets swapped in on hover — that colour shift is most of what makes the HUD feel alive.

Only nine need one. scrap, cores and energy live in the wallet readout, which is a static display — it is never hovered, so a variant for those is wasted work. The other nine all sit on buttons or tabs: inventory, defense, recall, close, chevron, weapons, robots, mods, materials.

Ask for it as a follow-up in the same chat, immediately after each icon — while that image is still in context. Asking later, or in a fresh chat, gets you a redraw rather than a recolour, and the silhouette will drift.

Now make the hover-state version of that exact icon.

This is a RECOLOUR, not a redraw. Keep the shape, proportions, line weights, negative space and composition pixel-identical to what you just made — the two images get swapped in place on mouse-over, so any shift in the silhouette will read as the icon jumping rather than lighting up.

Change only the colours: the dominant element becomes burnt orange #E07A3B, and any brushed silver or muted tan parts brighten to near-white #FFFFFF, as though the icon were lit from within. Leave near-black details black so the form still reads.

Same fully transparent background, same 1024x1024 canvas, same centring and margin.

Name the variant <key>_hover — so defense and defense_hover, close and close_hover, and so on. Same folder, same ImageLabel setup. I'll wire the button helper to look for that suffix and swap on MouseEnter, falling back to the plain tint when no variant exists — so a half-finished set still works, and each variant starts behaving the moment you add it.

After they're generated

  1. Check each at thumbnail size. Shrink it to about 24px. If it turns to mush, ask for a chunkier version — that is the only test that matters.
  2. Make sure the background is actually transparent. Image models often hand back a white or checkered square that only looks transparent. If it isn't, remove it before uploading, or you'll get a white box around every icon in game.
  3. Resize to 256×256. Roblox caps image assets at 1024 and downsamples anything larger; 256 is plenty for a 24px icon and keeps the upload small.
  4. Upload each to Roblox — Asset Manager → Images. Each comes back with an asset ID after moderation.
  5. In Studio, create an ImageLabel inside ReplicatedStorage.UiIcons, name it exactly the key from its card above (scrap, cores, …, all lowercase), and set its Image to that asset ID.

That's the whole handoff — the resolver already reads that folder. Anything missing falls back to text rather than breaking, so you can drop them in one at a time and watch them appear.

Still outstanding: the panel frame

Separate from the icons, and the thing that actually makes the HUD look angular rather than rounded. Not an AI-generation job — it's a precise shape, faster to draw by hand in any vector tool:

96×96 PNG, transparent, solid white. A rectangle with a square top-left corner, a 45° cut top-right, a square bottom-right, and a 45° cut bottom-left — the asymmetric cut from the reference. Cut size around 24px. Name it panelframe in the same folder.

It's white because this one is tinted at runtime — one asset gives every panel, button and tile its angular geometry, in whatever colour each needs.
